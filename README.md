# 📱 PhotoMatch – Android Mobil Kliens

A **PhotoMatch** platform megrendelőknek és látogatóknak szánt natív Android mobilalkalmazása.

## 🛠️ Technológiák
* **Nyelv:** Kotlin
* **UI Keretrendszer:** Jetpack Compose (Material Design 3)
* **Architektúra:** MVVM (Model-View-ViewModel)
* **Hálózati kommunikáció:** Retrofit + OkHttp (REST API integráció)
* **Képbetöltés:** Coil (Compose Image Loader)

## ✨ Főbb funkciók
* Fotósok és portfólióik böngészése, részletes szűrés (kategória, helyszín, felszerelés szerint).
* Magas felbontású képek és EXIF technikai paraméterek (váz, objektív, ISO, rekeszérték, záridő) megtekintése.
* Közvetlen ajánlatkérő űrlap beküldése a kiválasztott fotósnak.
* Beküldött ajánlatkérések státuszának (`pending`, `accepted`, `rejected`, `completed`) követése és értékelések leadása.
